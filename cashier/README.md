# 混音价格计算器

直接打开 `index.html`，或通过静态网站托管使用。请同时保留 `audio-analysis.js` 和 `translations.js`。

页面顶部可切换中文、日语和英语。界面、文件分析状态、错误提示、输入示例和无障碍标签随语言同步更新；浏览器会记住上次选择，无法保存偏好时仍可正常切换。切换语言不改变已添加文件、时长、手动开关或报价。所有语言使用相同的人民币计费规则，不进行货币换算。

## 干音计费

- 主人声、和声分别支持多文件选择、直接拖入上传框和分批追加。拖入时框会高亮，分析期间继续拖入的文件会排队处理。
- 每个文件扣除静音后的有效时长相加，并自动填入相应时间框，精确到百分之一秒。不同文件即使演唱时间重叠也分别计时；同一个立体声文件不会因有两个声道而重复计时。
- 添加、移除、清空文件或调整阈值时更新时长和费用。可以手动修改时间，也可以点击“重新填入时长”恢复检测结果。
- 纯静音文件计为零；读取失败的文件显示原因，不参与计费。
- 音频只在浏览器本地处理，不发送到服务器。格式支持取决于浏览器，建议使用 WAV。

检测前先将每个文件整体进行峰值标准化至 −6 dBFS：扫描所有声道的最大绝对采样值，再以同一个增益调整各声道，保留声道间的音量比例。只处理解码后的本地音频数据，不修改原文件；纯静音文件跳过标准化。

标准化后以 20 毫秒为一帧，测量各声道去除直流偏移后的均方根音量，采用默认 −60 dBFS 的阈值，忽略不足 60 毫秒的孤立声音。静音间隔不会补齐，文件末尾的不足一帧按实际长度计时。阈值可在 −70 至 −20 dBFS 之间调整，调整时使用缓存的标准化后音量结果，无需重新解码或重复标准化。

这是适用于纯人声干音的音量活动估算，不是人声分类模型：伴奏、呼吸和较响底噪也可能被计入，较轻人声可能被漏掉。请核对每个文件的检测时长，调整阈值或手动修正。

原有主音每分钟 30 元、和声每分钟 20 元、主音固定 70 / 20 元以及总价向下抹至 5 元档的规则保持不变。手动时间支持 `1.30`（1 分 30 秒）、`1:30` 和 `1:30.25`。

## 验证

使用 Node.js 内置测试，无需安装依赖：

```sh
node cashier/tests/audio-analysis.test.cjs
node cashier/tests/file-drop.test.cjs
```

从项目根目录运行。测试覆盖静音间隔、低音量、孤立杂音、直流偏移、立体声、末帧长度、多文件累加、时间进位、左右拖拽独立计费、分析期间追加、拖拽高亮及框外落下保护。
