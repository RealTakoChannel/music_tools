音频合并 · Music Tools

针对 48 kHz / 24-bit WAV 的离线无损拼接工具。

使用方法
1. Windows 版：双击「音频合并.exe」。优先使用 Edge 的独立应用窗口，未安装时使用 Chrome 或默认浏览器。
   网页版：解压「音频合并-离线网页版.zip」，双击 index.html。请保持 HTML、JS、CSS 文件在同一目录。
2. 将多个 WAV 拖入窗口，或者点击选择文件。软件自动按文件名升序排列，与选择或拖入顺序无关。
3. 文件名中的数字按自然顺序排列，例如 1.wav、2.wav、10.wav。追加文件后整个队列也会重新排序。
   排序固定，不提供手动调序；× 可移除。完全同名的文件按导入先后排列。
4. 间隔默认 1.5 秒，可在 1–2 秒之间以 0.1 秒为步长调整。
5. 输出名称默认使用按文件名排序后的第一个文件名，也可以手动修改。
   追加或移除文件改变第一项时，默认名称自动跟随；已手动填写的名称保持不变。清空队列后恢复默认命名。
   点击「合并并导出 WAV」，再点击「保存 WAV 文件」。
   浏览器会保存到下载目录，或按浏览器设置询问保存位置。可在浏览器下载设置中开启每次询问。
6. 可试听结果。浏览器若不支持对应 WAV 编码，仍可下载并在音频软件中播放。

音质与兼容性
· 直接拼接 WAV 原始采样数据，在文件之间插入对应长度的数字静音。
· 原音频不重新采样、不重新量化、不调音量、不淡入淡出。
· 48 kHz / 24-bit WAV 输出仍为 48 kHz / 24-bit WAV，保留原声道数和编码。
· 输入均为 WAV 且参数一致时，也支持 8/16/24/32-bit PCM、32/64-bit Float 及标准 WAVE_EXTENSIBLE。
· 参数不一致时阻止合并并提示原因。支持最多 500 个文件；只添加一个文件也可导出，不插入静音。
· 不会额外增加开头或结尾静音，不会去除文件本来就有的静音。
· 静音按完整采样帧取整，误差最多半个采样周期；48 kHz 时 1.0/1.5/2.0 秒均可精确表示。
· 不合并原有封面、标记点、BWF 描述、时间码等附加元数据。
· 超过 RIFF 4 GB 上限的输出自动改用 RF64 WAV，扩展名仍是 .wav，需要音频软件支持。
· 不支持 MP3、FLAC、AIFF、压缩 WAV、大端 RIFX 或非标准 RF64 扩展表。

隐私与运行要求
· 完全离线处理，不上传音频、不加载外部脚本、不需要账号。
· 推荐 Windows 10/11 的新版 Edge 或 Chrome。桌面启动程序使用 Windows 自带 .NET Framework，无需安装 Python 或 FFmpeg。
· 桌面启动程序会将网页资源保存到 %LOCALAPPDATA%\MusicTools\AudioJoiner，然后打开应用窗口。
  此目录只存放程序网页资源，不存放音频。卸载时删除 EXE 和上述资源目录即可。
· 桌面版使用浏览器引擎显示界面。关闭应用窗口即可结束使用，不会驻留后台音频服务。
· 大文件能否处理取决于浏览器、可用内存与磁盘空间。建议关闭其他占用资源的页面。
· 未进行代码签名；若系统提示未知发布者，可直接使用离线网页版。

开发与验证
· 核心：audiojoin/wav-engine.js
· 界面：audiojoin/index.html、style.css、app.js
· 测试：node --test audiojoin/tests/wav-engine.test.cjs
· 打包：powershell -ExecutionPolicy Bypass -File audiojoin/desktop/build.ps1
· 可以直接将 audiojoin 目录作为静态网页托管，无后端服务要求。
